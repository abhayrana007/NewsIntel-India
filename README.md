\# NewsIntel India



\## Cyber Threat Intelligence Dashboard



NewsIntel India is a Python-based dashboard for exploring and visualizing cyber incident data. It presents incident locations on a dark-themed map and provides charts, timeline analysis, filters, and an incident explorer.



\## Features



\- Dark-themed interactive incident map

\- Incident overview metrics

\- Attack-type and sector analysis

\- Monthly timeline from July 2024 to July 2026

\- Filters for country, sector, attack type, and verification status

\- Searchable incident explorer



\## Technology Stack



\- Python

\- Streamlit

\- Pandas

\- Plotly



\## Run Locally



1\. Install Python.

2\. Install dependencies:



&#x20;  `pip install -r requirements.txt`



3\. Run the dashboard:



&#x20;  `python -m streamlit run app.py`



\## Dataset



Place the dataset at `data/raw/NewsIntel\_final.csv`.



The dataset is not necessarily included in this repository. Only publish data you are authorized to share.



\## Data Limitations



Incident claims, verification labels, and geographic coordinates depend on the underlying sources. A plotted incident does not independently confirm that an attack occurred.
